# VoyageDesk AI v0.3 — Cloud Setup Checklist

VoyageDesk v0.3 runs immediately in **local prototype mode**. To turn on agent accounts and private cloud storage:

1. Create a Supabase project.
2. In Supabase, open **SQL Editor**.
3. Open `supabase-setup.sql` from this project, copy all of it into SQL Editor, and run it once.
4. Copy the project **URL** and **publishable key** from Supabase.
5. In the same PowerShell window where you run VoyageDesk, set:

```powershell
$env:SUPABASE_URL="https://YOUR-PROJECT.supabase.co"
$env:SUPABASE_PUBLISHABLE_KEY="YOUR-PUBLISHABLE-KEY"
$env:OPENAI_API_KEY="YOUR-OPENAI-KEY"
$env:PEXELS_API_KEY="YOUR-PEXELS-KEY"
npm.cmd start
```

6. Open `http://localhost:3000`.
7. VoyageDesk will show the new **Advisor Cloud** sign-in/create-account screen.
8. Create an agent account. Depending on your Supabase email settings, you may need to confirm the signup email before signing in.

## What becomes cloud-based

- Agent account/login
- My Trips
- My Clients
- Agency branding/profile
- Proposal data, including saved itinerary content and selected Pexels photo references

## Security model

The included SQL enables Row Level Security. Each table's policy checks that the signed-in user's ID matches the row's `user_id`, so one agent cannot query another agent's trips, clients, or agency profile through the app.

## Local fallback

If `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY` are not set, VoyageDesk stays in local development mode. Existing local trip saving continues to work. The Clients screen explains that cloud setup is required for persistent client records.
